# Raqsh 0.3.0

The project chooser and **Settings → About** identify your installed
edition. About displays the version, applicable license and bundled
notices. Both editions have the same board and agent features.

The public download is free for personal and other uses allowed by the
[PolyForm Noncommercial License](../../LICENSE). For commercial use,
see [Raqsh licensing](https://melashri.net/raqsh/#licensing).

The noncommercial edition checks for updates through GitHub in About.
Commercial updates come from your Ko-fi order.

The quick tour opens the first time you run this version, even with an
existing library. It guides you through opening a project, linking cards,
tracking progress, pairing an agent, and reviewing feedback. You can try
the exercises on a sample board or replay the tour from **Settings → Quick tour**.

Settings is available from the project chooser and the board menu. Choose
System, Light, or Dark, change the interface font and text size, or hide the
toolbar shortcut hints. Raqsh saves these preferences locally.

## Planning and review

- Start a board from a task brief, a starter template, or a pasted Markdown
  checklist. You can also load a GitHub issue by URL using your GitHub CLI
  login. Review and edit the cards before creating the board.
- Select cards and copy a Markdown agent brief with task details and
  prerequisites. Include the original task brief when you need that context.
- Record verification results against a commit or tag and copy a Markdown
  review summary. Board exports that include verification records require
  Raqsh 0.3.0 or later.
- Save, share and edit reusable board templates. Try the bundled Bug triage,
  Feature delivery and Release verification examples. Edit names, card text
  and priorities in the template library, or update the template from a board
  after changing its layout or dependencies.

## Linux installation

The x86-64 Linux archive can run from your home directory. Its installer
adds an app menu entry and puts the command in `~/.local/bin`. It uses the
system GTK 3 and WebKitGTK 4.1 libraries. [Install on Linux without sudo](../linux-install.md)
