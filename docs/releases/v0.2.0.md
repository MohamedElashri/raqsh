# Raqsh v0.2.0

- The board editor now uses Excalidraw for drawing and editing. Group and layer shapes, add frames and images, draw elbow arrows, reuse items from the local drawing library, or turn Mermaid text into editable shapes.
- Select, move, resize, duplicate, and delete task cards directly on the board. Undo and redo cover both task cards and drawings.
- The Agents panel adds setup for ten coding clients, including OpenCode and Pi. It shows the MCP configuration for the selected client and pairing.

Existing boards open in v0.2.0. Editing a drawing can save it in the new scene format, which requires v0.2.0 or later. Keep a backup of any board you may need to reopen in v0.1.0. Images count toward the existing 8 MiB board limit.
