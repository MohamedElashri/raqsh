# Raqsh v0.2.0

- Draw with Excalidraw, including images, frames, and editable Mermaid diagrams.
- Edit task cards directly on the board, with shared undo and redo for cards and drawings.
- Set up ten additional MCP clients from Agents, including OpenCode and Pi.
- Use a color picker styled for light and dark mode.

Existing boards open in v0.2.0. Boards saved in the new drawing format require v0.2.0 or later.
