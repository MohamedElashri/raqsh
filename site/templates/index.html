Works with Codex and Claude Code.

Raqsh bundles a local MCP server. Within the access you grant, paired clients can read and edit cards, connect dependencies, update statuses, and respond to feedback.

Pair an agent

Open Agents, choose Codex or Claude Code, and approve the pairing. Raqsh adds its MCP server to the client’s settings. Start a new session in that client to use the board tools.

Pairings are board-scoped by default. You can explicitly approve project-wide access or revoke a pairing in the app.

Boards are stored on your device. Paired clients may connect to their own services.

Install via terminal

The installer checks the package against the release checksum. A matching checksum verifies package integrity. Trust in the publisher requires separate verification.

curl -fsSL {{ $installer }} | sh
wget --https-only -qO- {{ $installer }} | sh
macOS first launch

Unzip the download and move Raqsh to Applications. The app is ad hoc signed, and Gatekeeper may block it because Apple hasn’t notarized it.

If you downloaded the ZIP manually, verify it against SHA256SUMS from the same release before removing quarantine. The shell installer verifies the download and installs Raqsh in ~/Applications.

If Gatekeeper blocks the verified app, type xattr -dr com.apple.quarantine followed by a space in Terminal. Drag your installed copy of Raqsh from Finder into Terminal to add its path, then press Return.

Frequently asked questions

Which operating systems and processors are supported?

Raqsh ships a universal ZIP for Apple silicon and Intel Macs, a DEB for x86-64 Ubuntu and Debian, and an RPM for x86-64 Fedora. For the DEB, use Ubuntu 24.04 or later, or Debian 13 or later.

Which coding agents can I pair?

Raqsh sets up MCP for Codex and Claude Code from the Agents panel. Start a new client session after approving the pairing.

Where are my boards stored?

Raqsh stores boards on your device. A paired agent can read the boards you grant it access to through MCP, and its client may send requests to its own provider.

Why does macOS show a first-launch warning?

Raqsh is ad hoc signed and has no Apple notarization ticket. If Gatekeeper blocks it, follow the macOS first-launch instructions to verify the download before allowing your installed copy to open.

Can I use Raqsh commercially?

The PolyForm Noncommercial License 1.0.0 permits personal and other noncommercial uses under its terms. Commercial use outside those terms requires a separate license.
