Review your agent’s plan on a board

Turn a plan into task cards, then pair Codex or Claude Code to share progress and send feedback. Your boards stay on your device.

Plan, review, and follow the work

  1. Put the plan on the board

    Ask Codex or Claude Code to turn its plan into task cards and connect the steps that depend on each other.

  2. Mark up the plan

    Sketch, circle, or move cards as you review. Use Queue feedback to tell your agent what to change.

  3. Follow the agent’s reply

    Your agent can acknowledge feedback, reply on the board, and update cards as work starts or finishes.

Need to pause the work? Queue “Pause packaging until we review the checks” and ask your agent to read the feedback.

What Raqsh adds to Codex and Claude Code

  • A bundled MCP server. Every macOS and Linux package ships with the local Raqsh MCP server.
  • Automatic client setup. Choose Codex or Claude Code in Agents and approve the pairing. Raqsh adds the server to that client’s MCP settings. Start a new session to use it.
  • Tools for the board. Read the plan, create and edit cards, link dependencies, and update task status.
  • Tools for feedback. Read queued feedback, acknowledge it, and reply on the board.
  • Board-scoped access. A pairing gets access to the current board by default. You can grant access to the whole project when pairing.

Choose Revoke pairing in Agents to end access and remove the pairing’s MCP entry.

macOS first launch

Gatekeeper may block Raqsh because the app isn’t notarized by Apple. The shell installer verifies the download. If you downloaded the ZIP manually, verify it against the release’s SHA256SUMS first.

If Gatekeeper blocks the verified app, type xattr -dr com.apple.quarantine followed by a space in Terminal. Drag your installed copy of Raqsh from Finder into Terminal to add its path, then press Return. The shell installer puts Raqsh in ~/Applications.
