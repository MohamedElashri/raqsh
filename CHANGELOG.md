# Changelog

## v0.2.3

- Add a visible Ko-fi tip button to the About header and a matching badge to the README.

## v0.2.2

- Open the Add Card draft when you press N during board sync.
- Keep loaded feedback history visible as new feedback arrives or an older item is cancelled.
- Reject stale revision requests when reading across MCP snapshot sections.
- Expand About with project links, creator credit, and offline license information.

## v0.2.1

- Install the optional Raqsh skill from Agents to guide board selection, task updates, and feedback across supported coding clients.
- Save the skill for manual setup or read it from the Raqsh website.

## v0.2.0

- Draw with Excalidraw, including images, frames, and editable Mermaid diagrams.
- Edit task cards directly on the board, with shared undo and redo for cards and drawings.
- Set up ten additional MCP clients from Agents, including OpenCode and Pi.
- Use a color picker styled for light and dark mode.

Existing boards open in v0.2.0. Boards saved in the new drawing format require v0.2.0 or later.
